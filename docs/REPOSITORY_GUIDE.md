# Repository guide

Use [docs/INDEX.md](INDEX.md) to choose a current guide; root README is the short entry point. Avoid using a historical comparison's settings as a new deployment recipe.

## Implementation

| File | Responsibility |
| --- | --- |
| `src/avl_white_lines/original_viewer.py` | Original native-resolution color/Hough program; unchanged reference |
| `detector.py` | Backend dispatcher, backward-compatible observations/frame results, candidate rendering |
| `ridge.py`, `ground.py`, `camera.py` | Adapted Marvin ridge/flat-ground algorithms, presets and geometry |
| `region.py` | Explicit normalized image crop; not ground confirmation |
| `components.py` | Sampled curved centerlines, physical diagnostics and metric association cost |
| `tracking.py` | One-to-one matching, smoothing, confirmation, held/expired states |
| `navigation.py` | Conservative navigation eligibility, masks/points, block reasons and receiver watchdog helper |
| `calibration.py` | Rectified CameraInfo and registration validation without a ROS dependency |
| `cli.py` | Image/video/camera viewer, stage export, JSONL and local timing |
| `ros_node.py` | Latest-frame ROS adapter, candidate/navigation topics, depth pairing and invalidation |
| `config.py`, `default.json` | Validated settings and compatibility defaults |

`MARVIN_PROVENANCE.md` records upstream attribution and unspecified licensing. No copied upstream checkout is required to run AVL; a separate Marvin checkout is needed only for direct upstream comparison scripts.

## Data and configuration

`examples/raw/` contains only the five user-selected raw frames. `examples/generated/` and the original offline gallery retain the original results. They are not regenerated by current ridge comparisons. Full recordings, bags and temporary results stay outside tracked source.

[config/README.md](../config/README.md) explains each profile. Copy robot templates into ignored `config/local/`; do not edit a shared preset into an undocumented personal mount. Each camera has independent tracking and measured calibration/TF.

## Verification and reports

```bash
python -m pytest tests -q
python scripts/check_original_reference.py --strict-bytes
python scripts/check_docs.py
python -m compileall -q src scripts launch
```

The strict PNG-byte check is a local reproducibility check; CI requires original pixel equality across supported Python environments. ROS callback tests use message doubles and do not validate middleware/drivers/hardware.

`validation/ground_improvement.json` is the current sparse audit/runtime record. Earlier JSON/Markdown reports remain dated history; see [validation index](../validation/README.md). Generated current visual galleries go under `results/` or a user-selected output directory.

## Maintenance

Keep candidate evidence separate from navigation evidence. Add regression scenes for a real failure before changing segmentation thresholds. Run original references to protect the user's earlier program. Document calibration assumptions, mask-versus-fit comparisons and missing ground truth alongside new metrics. Avoid claiming an accuracy improvement from a crop count or a synthetic fixture alone.
