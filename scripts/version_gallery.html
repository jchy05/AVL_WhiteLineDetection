Available AVL and Marvin versions

Real detector reruns from preserved Git commits on identical raw images. Each card links to its lossless result and source record. Original AVL keeps its original colors; cyan on other versions shows the actual candidate mask or fitted lines. These are single-frame results, without temporal confirmation, depth or measured accuracy scores.

Sources, settings and limitations

Original/Hough masks are fitted-line drawings, including inferred extensions; ridge masks are segmented candidate pixels. Different processing widths and crops are labeled in each source record. Color or a cleaner picture does not establish correctness. Historical code uses today's installed Python/OpenCV, so this is a reproducible rerun rather than a claim to reproduce its original runtime environment.
